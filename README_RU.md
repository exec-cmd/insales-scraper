# Inscrap

Inscrap представляет собой небольшую консольную утилиту для выгрузки каталогов магазинов на
[InSales](https://www.insales.ru/). Она берёт ссылки на товары из `sitemap.xml`,
запрашивает данные через JSON API магазина и сохраняет результат в файл.

Утилита пригодится, когда нужно быстро получить названия, описания, цены,
остатки, изображения и варианты товаров без ручного обхода каталога.

[English version](README.md)

## Быстрый старт

Нужен Python 3.13 или новее и, желательно, [uv](https://docs.astral.sh/uv/).

Запустить Inscrap из клонированного репозитория можно без отдельной установки:

```bash
uv run inscrap run https://shop.example.com -o products.xlsx
```

Вместо адреса магазина можно передать прямую ссылку на sitemap:

```bash
uv run inscrap run https://shop.example.com/sitemap.xml
```

Если не указывать `-o`, результат сохранится в `products.json` в текущем
каталоге.

## Установка

Чтобы запускать `inscrap` из любого каталога, установите его как глобальный
инструмент `uv`:

```bash
uv tool install .
```

Проверить установку можно так:

```bash
inscrap run --help
```

Также можно собрать и установить wheel:

```bash
uv build
uv tool install dist/insales_scraper-1.0-py3-none-any.whl
```

Или установить wheel по конкретному пути:

```bash
uv tool install /path/to/insales_scraper-1.0-py3-none-any.whl
```

Удалить глобальную установку:

```bash
uv tool uninstall insales-scraper
```

## Использование

После установки команда выглядит так:

```bash
inscrap run URL [OPTIONS]
```

Формат результата определяется расширением выходного файла:

```bash
inscrap run https://shop.example.com -o products.json
inscrap run https://shop.example.com -o products.csv
inscrap run https://shop.example.com -o products.xlsx
inscrap run https://shop.example.com -o products.txt
```

Каталог для выходного файла должен существовать заранее:

```bash
mkdir -p data
inscrap run https://shop.example.com -o data/catalog.xlsx
```

### Параметры запросов

| Параметр | Что делает | По умолчанию |
| --- | --- | --- |
| `-o`, `--output` | Путь к результату. Формат определяется расширением `.json`, `.csv`, `.xlsx` или `.txt`. | `products.json` |
| `-c`, `--concurrency` | Количество одновременных запросов, от 1 до 50. | `5` |
| `-r`, `--retries` | Количество повторных попыток после ошибки запроса. | `5` |
| `-t`, `--transport` | HTTP-транспорт: `httpx` или `curl_cffi`. | `httpx` |
| `-f`, `--fatalist` | Остановить выгрузку после первой ошибки запроса товара. | выключен |

Для большого каталога увеличивайте параллелизм постепенно, чтобы не создавать
лишнюю нагрузку на магазин:

```bash
inscrap run https://shop.example.com -c 10 -r 3 -o catalog.csv
```

Посмотреть доступные HTTP-транспорты:

```bash
inscrap transport
```

## Что попадёт в выгрузку

Для каждого товара сохраняются идентификатор, название, описание, ссылка,
наличие, изображения и варианты. У каждого варианта есть собственные
идентификатор, название, SKU, штрихкод, статус наличия, остаток, текущая и
старая цена.

| Формат | Структура данных |
| --- | --- |
| JSON | Полная вложенная структура с товарами и их вариантами. |
| CSV / XLSX | Одна строка на вариант. Поля товара повторяются для каждого его варианта. |
| TXT | Текстовое представление загруженных товаров. |

## Как это работает

1. Inscrap открывает переданный `sitemap.xml`. Если передан адрес магазина, к нему добавляется `/sitemap.xml`.
2. Из sitemap берутся ссылки, содержащие `/product/`.
3. Для каждого товара запрашивается JSON-версия его страницы, к URL добавляется `.json`.
4. Успешно загруженные товары сохраняются в выбранный файл. По умолчанию товары с ошибками пропускаются, а их количество попадает в итоговую статистику.

## Стек

Для CLI используются `Typer` и `Rich`, для HTTP-запросов `httpx` и
`curl-cffi`, для экспорта `polars` и `xlsxwriter`.
